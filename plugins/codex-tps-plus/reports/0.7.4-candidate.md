# 0.7.4：恢复本轮、近期、会话三个自动速度

日期：2026-10-03。用户希望自动 Hook 提供当前速度与历史比较，本版恢复三个速度，并在提交前审查中加固异常证据校验；不改变 measurementVersion=3 的计时与用量口径。

默认 Hook 明确显示本轮生成估计、近期加权估计及会话加权估计，并保留输出 token 数、短输出提示、本轮不可测原因。近期最多 5 个有效轮次；会话使用全部已保存的同设置有效轮次，两个历史值都标实际有效样本数。仅有一个样本时三项可能相同；无样本明确显示暂无有效样本。

JSON 新增 sessionGeneration，与 recentGeneration 共享模型/provider/effort、方法版本及完整计时覆盖的过滤规则，使用总 token 间隔 / 总生成窗口时间加权。近期和会话不使用旧 session.throughput 的整轮耗时。旧版本、其他设置、部分覆盖和不可测轮次均不纳入。当前轮不可测时，历史值仍可独立展示。

历史统计基于保留记录，现有每会话 200 状态文件 / 2 MiB 上限保持；字段 historyScope 明确为 retained-session-records。极长会话的旧文件裁剪后不声称无限完整生命周期平均。可选查询 Skill 同步三个结果的范围及样本限制。

自动执行仍是本地确定性脚本，不发起模型请求，不配置 OTel 或开启 observer。稳定运行快照随安装切换；已有 0.7.3 数字记录无需迁移或重算。

## 提交前审查修复

新增四项回归测试先复现失败，再修复：非对象 JSON 日志（包括 null）不再使解析中断，保留用量并明确令生成覆盖无效；直接匹配工具 ID 也不能绕过冲突或无效的返回时间；相同原生工具 ID 与时间但类型冲突时拒绝计时；保存记录的生成 token 数和普通响应数必须与普通响应覆盖摘要一致，否则本轮、近期、会话与模型分组均排除该速度。正常完整覆盖记录保持原公式与结果。

## 验证

141 项本机测试通过。历史比较验证总 token 间隔 / 总生成窗口时间加权，近期 5 个样本与会话 7 个样本得到不同值；当前不可测仍独立显示，模型/provider/effort 切换和旧计时版本不混入。真实本地查询及禁用网络 API、网络模块、子进程的生产 Hook 检查通过。

CLI 0.153.4、0.159.2、0.160.0 各通过 10 项隔离安装/升级检查，模型请求数均为 0。候选结构检查和差异检查通过后同步本机 0.7.4；CLI 本身保持 0.159.2。没有额外模型测量。远端 CI 结果以对应提交的 GitHub Actions 为准。

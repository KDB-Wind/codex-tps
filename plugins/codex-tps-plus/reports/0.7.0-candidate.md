1. 用量与展示：适配显式逐响应 usage、处理旧镜像、区分压缩范围、缩减默认行、按模型设置分组。
2. 输出速率与兼容：严格校验逐响应输出窗口、覆盖不完整时回退、保留旧状态与延迟回填、增加 CLI 安装/升级验证。

## 指标契约

完整计时覆盖时，默认行如下：

```text
⚡ 输出速率估计 ≈32.8 tok/s · 输出 2.5k tok
```

计算方式为普通响应总输出 token 除以对应输出窗口的总秒数，包含 reasoning 与有可靠结束证据的工具参数。已识别压缩不进入该指标。一个响应内使用完整跨度，重叠项只算一次，但保留跨度内的间隔。它是客户端日志估计，不能称为服务端纯解码 TPS。

任一普通响应缺少可靠计时、用量身份或输出覆盖时，默认行回退为整轮吞吐：

```text
⚡ 非推理整轮吞吐 ≈16.2 tok/s · 非推理输出 2.5k tok
```

非推理分子为 `output_tokens - reasoning_output_tokens`，分母包含首字等待、工具执行和客户端开销。reasoning 拆分缺失时，显式改称总输出整轮吞吐。Stop 墙钟分母保留近似标记，完成事件回填后使用完成时长。

默认行只有速率与输出数。`$tps` / `status.mjs --json` 提供范围、覆盖率、排除理由、TTFT 与历史详情；`--verbose` 保留旧详细行。默认行不附带其他轮次的 TTFT。

## 用量与计时边界

- 显式记录只读取单响应 `usage`，不把 `turn_token_usage`、`thread_token_usage` 累加。按响应 ID 去重，冲突重复记录使当轮不可用。
- 相邻旧镜像不重复计数，缺失的旧 reasoning 细节由显式记录补全。未被显式记录覆盖的旧响应补计用量，但不能提供完整输出速率。
- 相同 token 数的不同响应保持独立；缺少累计去重证据的未覆盖旧用量不猜测合并。
- 排除其他 thread/turn 及当前起点前的 fork 历史。中断轮次不产生完成速率。
- 压缩关联依赖相邻显式用量与压缩完成记录。证据不足时保留未归类范围，不冒充普通生成。
- 工具先出现、零时长输出项、缺失输出项、原始输出缺少对应计时项、解析缺口、未配对输出、响应窗口重叠均会回退。
- 工具调用记录在工具执行开始后才落盘时，不能拿其落盘时间当作参数生成结束点。不能确认工具开始点时同样回退。
- 短输出保留并提示噪声，不以任意高低速度阈值过滤。

状态 schema 升为 7，并兼容读取 v1–v6。完成时长和 TTFT 仍独立回填；输出窗口速率不被整轮时长回填覆盖。新增适配器包含在版本无关的运行时快照中。

模型、provider、reasoning effort 只采用日志中观察到并经过字符白名单校验的标签。缺失设置保持未知。`modelGroups` 使用 token/时间加权；旧 `session` 汇总字段保留兼容，可能包含不同模型。

生产状态只保存数字汇总、哈希 turn ID 与校验后的设置标签，不新增正文、工具参数、完整响应 ID、完整 thread ID 或 transcript 路径持久化。

## 本机日志只读复算

未复制日志或保存会话内容。以下只记录脱敏数值，使用完成事件给出的整轮时长：

| 样本 | 0.6.0 非推理整轮吞吐 | 总输出整轮吞吐 | 0.7.0 输出速率估计 |
|---|---:|---:|---:|
| 93.274 秒，输出 1,126，reasoning 259 | 9.30 tok/s | 12.07 tok/s | 18.75 tok/s，2/2 普通响应完整覆盖，窗口 60.050 秒 |

这说明原先的低值主要受到分子与时间范围影响，不能据此断言服务端生成速度提高，也不能把它与其他测试的 TPS 直接比较。

另一个 1,429.303 秒的工具密集样本：旧记录计得普通输出 24,901；显式记录另有压缩输出 3,319；新版总消耗为 28,220，reasoning 为 11,565。压缩消耗单列，不进入普通输出速率。该轮 19 个普通响应仅 1 个有合格窗口，17 个无法确认参数生成结束点，1 个工具先出现，因此输出速率为空，保留整轮吞吐。

## 剩余限制

尚未在受控纯文本/工具请求中，将日志窗口与官方流式事件计时逐一对照；当前没有生成 TPS 误差、稳定中位数或跨平台交互式 TUI 的新验证结论。

逐响应关联仍依赖 transcript 的观察格式与事件顺序。普通复杂工具轮经常缺少完整参数生成计时，因此不会保证每一轮都显示输出速率。格式变化时优先回退或不显示，不能放宽覆盖规则来人为抬高数字。

CLI 原生底栏没有通用脚本 TPS 扩展项；当前仍通过 Stop `systemMessage` 显示完成轮次的信息。此次未启用 App Server 观察探针、OTel 捕获、网络代理或实时逐 token 展示。
